# 🧬 LifeSci Insight

### AI-Assisted Life Sciences Strategy & Intelligence Platform

**LifeSci Insight** is an interactive pharmaceutical strategy and analytics platform built with Python and Streamlit. It combines commercial valuation, competitive intelligence, clinical trial benchmarking, patent-cliff analysis, health technology assessment and key opinion leader mapping in one workspace.

The project demonstrates how analytical modelling, interactive dashboards and AI-assisted interpretation can support structured decision-making in the life sciences industry.

## Platform Capabilities

| Module | Function |
|---|---|
| **rNPV Valuation** | Estimates risk-adjusted pharmaceutical asset value using commercial forecasts, approval probabilities and discounted cash flows. |
| **Competitive Landscape** | Compares pharmaceutical companies, pipeline assets, mechanisms of action and development stages. |
| **Clinical Trial Benchmarking** | Analyses trial enrolment, duration, study design, phases and endpoints. |
| **Patent Cliff Tracker** | Models loss-of-exclusivity timing, revenue exposure and potential sales erosion. |
| **HTA & Market Access** | Explores cost-effectiveness, ICERs, pricing assumptions and reimbursement considerations. |
| **KOL Mapper** | Maps clinical experts using research activity and illustrative influence-scoring methods. |
| **AI Strategic Insights** | Produces structured strategic briefs from analytical outputs, with optional AI-assisted interpretation. |
| **Deck Export** | Generates editable PowerPoint presentations incorporating analytical findings. |

## Technology Stack

- **Python** — data processing and financial modelling
- **Streamlit** — interactive web application
- **Pandas and NumPy** — data analysis
- **Plotly** — interactive visualisation
- **python-pptx** — PowerPoint generation
- **OpenAI API** — optional AI-assisted strategic interpretation

## Example Consulting Applications

LifeSci Insight can support illustrative analyses such as:

- Evaluating the commercial potential of a pharmaceutical asset
- Benchmarking competing clinical development programmes
- Identifying potential revenue exposure from loss of exclusivity
- Exploring market-access and pricing scenarios
- Developing structured executive summaries and strategy presentations

## Running Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Launch the application:

```bash
streamlit run app.py
```

## Methodology and Limitations

The platform is an independent portfolio project developed for educational and analytical demonstration purposes.

Starter datasets contain fictional examples. Financial forecasts, risk adjustments, cost-effectiveness calculations and expert scoring rely on simplified assumptions and should not be interpreted as validated investment, clinical or reimbursement advice.

AI-generated content, when enabled, requires independent verification before professional use.
